TableGrab

One click copies any web table as Markdown, CSV or TSV.

No row limits. No subscription. No account. No data collected. The popular table tools cap your free exports and paywall the formats you actually need. TableGrab just copies the table.

Unlimited rows Markdown, CSV and TSV No account MIT licensed

Why this exists

Table Capture (the category leader) limits free exports to 250 rows, and puts CSV and Excel downloads and Markdown copying behind its paid subscription.

TableClipper limits free use to 100 rows.

TableGrab has no caps at all, because a table copy is a small local job your browser can do for free. The whole tool is open source, so you can read exactly what it does.

Competitor limits as published on their own listings and pricing pages in October 2026.

What it does

Hover and copy

Turn on copy buttons from the popup, hover any table on the page, and pick Markdown, CSV or TSV from the small gold control.

Largest table, one click

The popup can copy the biggest table on the page (by row count) in any format, without hunting for it.

Clean output

Headers come from the table header or the first row of header cells. Pipes are escaped in Markdown, quotes are escaped in CSV, and stray whitespace is collapsed.

Private by design

No analytics, no server, no account. The extension only touches a page when you click, using the activeTab permission. See the README for the full permission story.

Install in Chrome

  1. Download or clone this repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click "Load unpacked" and select the extension folder from this repo.
  4. Pin TableGrab, open any page with a table, and click the icon.

Firefox note: the extension uses standard WebExtensions APIs. It can be loaded temporarily from about:debugging using the same extension folder, though Chrome is the tested target for v1.
